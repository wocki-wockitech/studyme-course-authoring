# Определения (глоссарий)

Определения — это термины вашего курса, которые платформа автоматически подсвечивает в тексте уроков и агрегирует в общий глоссарий.

## Формат файла

Определения хранятся в `defs/` рядом с `lesson.md`:

```
my-lesson/
  lesson.md
  cards/
  defs/
    goroutine.yaml
    channel.yaml
```

Каждый файл — один термин:

```yaml
id: ""                        # auto-filled
term: "Горутина"
aliases:
  - "горутина"
  - "горутины"
  - "goroutine"
  - "goroutines"
tags: [go, concurrency]

definition: |
  Легковесный поток выполнения в Go,
  управляемый рантаймом.

example: |
  go func() { fmt.Println("hello") }()

related: [channel]
```

> [!info] Aliases
> В aliases перечисляются все словоформы термина на всех языках. Платформа матчит регистронезависимо.

## Три уровня использования

### 1. Авто-линковка (автоматически)

Просто пишите текст — платформа сама найдёт совпадения с aliases и покажет tooltip при наведении. Ноль усилий.

### 2. Явная подсветка — `((термин))`

Если хотите принудительно подсветить конкретное слово, оберните его в двойные круглые скобки:

```markdown
Каждая ((горутина)) выполняется в своём стеке.
```

### 3. Блок-карточка — `:::def slug`

Для визуального акцента при введении термина:

```markdown
:::def goroutine
:::
```

| Синтаксис | Результат |
|-----------|-----------|
| `:::def slug` | Полная карточка |
| `:::def slug --no-example` | Без примера |
| `:::def slug --compact` | Однострочный вариант |

## Живой пример

Ниже — реальное ((определение)) в действии (авто-линковка по alias). А вот блок-карточка:

:::def definition
:::

## Мультиязычные определения

Поля `term`, `definition` и `example` поддерживают формат `LocalizedText`:

```yaml
term:
  ru: "Горутина"
  en: "Goroutine"
definition:
  ru: |
    Легковесный поток выполнения в Go.
  en: |
    A lightweight thread of execution in Go.
```

Поле `aliases` — общий массив для всех языков.

## Настройка авто-линковки

В `course.yaml`:

```yaml
definitions:
  auto_link: true            # вкл/выкл (по умолчанию true)
  first_occurrence: section  # section | lesson | all
```

В frontmatter урока (отключить конкретные термины):

```yaml
skip_defs: [http, api]
```

## Что происходит при sync

1. Определения индексируются в глоссарий курса
2. Автоматически создаются SR-карточки (flashcard: термин ↔ определение)
3. Aliases агрегируются для авто-линковки по всему курсу

> [!tip] Проверка
> Запустите `studyme-action lint .` — линтер проверит обязательные поля и уникальность aliases.
