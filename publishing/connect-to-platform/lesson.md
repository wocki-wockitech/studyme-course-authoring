# Подключение к платформе

После создания тега курс готов к публикации на StudyMe.

## Шаг 1: Перейдите в StudyMe

Откройте раздел **"Мои курсы (автор)"** в навигации StudyMe.

## Шаг 2: Подключите репозиторий

Нажмите **"Подключить курс"** и вставьте URL вашего GitHub-репозитория:

```
https://github.com/<your-username>/studyme-course-<topic>
```

## Шаг 3: Платформа проиндексирует курс

Платформа:
1. Найдёт последний тег (например `v1.0.0`)
2. Скачает репо на этом теге
3. Распарсит `course.yaml`, все блоки и уроки
4. Загрузит markdown и ассеты в хранилище
5. Курс появится в каталоге

> [!tip] Публичные репо
> Для публичных GitHub-репо токен не нужен — платформа скачивает через открытый API.
> Для приватных потребуется GitHub App авторизация (V2).

## Обновление курса

Когда хотите обновить опубликованный курс:

1. Внесите изменения в контент
2. Закоммитьте и создайте новый тег: `git tag v1.1.0 && git push --tags`
3. Нажмите **"Sync"** на платформе (или дождитесь автоматического sync через webhook)

Студенты увидят обновлённый контент автоматически. Их прогресс сохранится — мы матчим по UUID.
